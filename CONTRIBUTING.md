# Contribuir a PonteCapas

Gracias por tu interés en mejorar el proyecto.

## Cómo contribuir

- **Errores o bugs**: abre un issue describiendo el problema, qué esperabas que ocurriera y cómo reproducirlo.
- **Sugerencias**: abre un issue con la mejora propuesta y por qué sería útil.
- **Cambios de código**: si quieres enviar un PR, hazlo pequeño y enfocado en un solo cambio.

## Antes de abrir un PR

1. Explica brevemente el problema o mejora.
2. Indica qué archivos has modificado.
3. Si cambias la lógica de recomendación, describe el comportamiento anterior y el nuevo.
4. Prueba el cambio en Scriptable/iPhone cuando sea posible.

## Estilo

- Mantén el código simple y fácil de leer.
- Evita añadir dependencias innecesarias.
- Conserva la compatibilidad con el flujo actual de Atajos + Scriptable.
- Escribe mensajes de commit claros.

## Alcance del proyecto

PonteCapas es un proyecto simple para recomendaciones de vestimenta en iOS. Las mejoras deben priorizar la claridad, la utilidad práctica y la facilidad de uso.
