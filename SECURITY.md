# Seguridad

Si encuentras un problema de seguridad o privacidad en PonteCapas, **no lo publiques en un issue público**.

## Cómo reportarlo

- Usa la opción de **Private vulnerability reporting / Security advisory** de GitHub si está disponible en este repositorio.
- Si no está disponible, contacta al mantenedor por un canal privado antes de hacer público el problema.

## Qué incluir

- Descripción del problema.
- Pasos para reproducirlo.
- Impacto posible (por ejemplo: datos expuestos, comportamiento inesperado, permisos).
- Una propuesta de solución, si la tienes.

## Alcance

Este proyecto guarda datos localmente en Scriptable y consulta la API de Open-Meteo. Los reportes más relevantes suelen estar relacionados con:

- Exposición accidental de datos.
- Manejo incorrecto de ubicación o historial.
- Comportamiento que pueda comprometer la privacidad del usuario.
