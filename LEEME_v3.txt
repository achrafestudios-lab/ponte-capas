ROPA DIARIA v3.0 - INSTALACION
================================

OBJETIVO
La automatizacion de las 07:30 ya no muestra preguntas ni abre ventanas.
Atajos obtiene la ubicacion GPS y pasa las coordenadas al script de Scriptable.
El script consulta Open-Meteo, guarda la recomendacion y programa una notificacion.

CONTENIDO DEL PAQUETE
- ropa_diaria.js: motor automatico sin interfaz.
- configurar_transporte.js: selector manual de coche/autobus.
- ver_outfit_hoy.js: ficha visual que se abre al tocar la notificacion.
- valorar_outfit.js: registra frio, calor, viento, lluvia o dia perfecto.
- historial_ropa.js: consulta las recomendaciones guardadas.

ANTES DE EMPEZAR
1. Mantén instaladas Scriptable y Atajos.
2. No borres los datos de Scriptable. La v3 reutiliza los archivos JSON de la v2.
3. Haz una copia del script actual Ropa diaria si quieres conservar la v2.

PASO 1 - INSTALAR LOS SCRIPTS
1. En Scriptable, abre el script existente llamado exactamente "Ropa diaria".
2. Sustituye todo su contenido por ropa_diaria.js y guarda.
3. Crea un script "Configurar transporte" y pega configurar_transporte.js.
4. Crea un script "Ver outfit hoy" y pega ver_outfit_hoy.js.
5. Conserva "Valorar outfit" e "Historial ropa" de la v2. Si no los tienes, importa los dos archivos incluidos.
6. Ejecuta "Configurar transporte" una vez con el iPhone desbloqueado y elige coche o autobus.

PASO 2 - MODIFICAR LA AUTOMATIZACION DE LAS 07:30
Conserva el disparador de hora de las 07:30 y la repeticion diaria.
Dentro de las acciones, deja este orden:

A. Accion de Atajos: "Obtener ubicacion actual".
B. Accion: "Obtener detalles de ubicaciones".
   - Entrada: la ubicacion actual del paso A.
   - Detalle: "Latitud".
C. Accion: otra vez "Obtener detalles de ubicaciones".
   - Entrada: la misma ubicacion del paso A.
   - Detalle: "Longitud".
D. Accion "Texto".
   Escribe el resultado de Latitud, luego el separador |, y despues Longitud.
   Debe quedar: [Latitud]|[Longitud]
   Inserta las variables magicas de los pasos B y C; no escribas las coordenadas a mano.
E. Accion Scriptable: "Run Script".
   - Script: Ropa diaria.
   - Parameter: el resultado del paso D (Texto).
   - Run In App: DESACTIVADO.
   - Show When Run / Mostrar al ejecutar: DESACTIVADO.

Si tu automatizacion actual contiene la accion Run Script con Run In App activado,
desactiva esa opcion. El script automatico no tiene Alert ni WebView.

PASO 3 - PERMITIR EJECUCION BLOQUEADO
1. En la automatizacion/atajo, abre su informacion (boton i o menu equivalente).
2. En Privacidad, activa "Allow Running When Locked" / "Permitir ejecucion con el iPhone bloqueado", si aparece.
3. Desactiva cualquier opcion equivalente a "Preguntar antes de ejecutar" o "Confirmar antes de ejecutar".
4. Guarda.

PASO 4 - PERMISOS Y PRIMERA PRUEBA
La primera vez, ejecuta la automatizacion manualmente con el iPhone desbloqueado.
Concede los permisos de ubicacion a Atajos y de notificaciones a Scriptable si iOS los solicita.
Luego cambia temporalmente el disparador a una hora dentro de 2-3 minutos.
Bloquea el iPhone y espera. Si todo va bien, recibiras la notificacion sin abrir Scriptable.
Despues restaura la hora a 07:30.

USO DIARIO
- 07:30: Atajos obtiene GPS y lanza la recomendacion sin preguntar transporte.
- El transporte usa la ultima preferencia guardada en "Configurar transporte".
- Tocar la notificacion abre "Ver outfit hoy" y muestra la ficha visual completa.
- 20:30: Scriptable programa un recordatorio para valorar el outfit.
  Al tocar el recordatorio, desbloquea el telefono si te lo pide y se abre "Valorar outfit".
- "Historial ropa" muestra las recomendaciones anteriores.

IMPORTANTE: LIMITES DE IOS
No puedo garantizar desde aqui que tu iPhone ejecute correctamente la accion con la pantalla bloqueada.
Depende de iOS, permisos, version de Scriptable y de que la accion Run Script pueda ejecutarse
sin abrir la app en tu configuracion. Por eso es imprescindible hacer la prueba temporal con el
telefono bloqueado antes de dar la automatizacion por terminada.
La notificacion puede llegar bloqueado; abrir la ficha visual y registrar una valoracion son
acciones interactivas y pueden requerir desbloquear el telefono.

DATOS Y PRIVACIDAD
El historial y el perfil se guardan localmente en Scriptable. Las coordenadas se pasan desde
Atajos al script y se redondean a tres decimales al consultar Open-Meteo. No se guarda la
coordenada exacta en el historial.
